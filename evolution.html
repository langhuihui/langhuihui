串行循环

交代 → 执行 → 检查 → 再交代

多 Agent 并行

一个人 · 多个 Agent · 同时开发

调度 Agent

人 → 调度 Agent → 多个 Agent
✓ 人只对接一个调度 Agent✓ 冲突由调度协调✗ 调度忙不过来，人要排队

需求落入待办 · 调度巡检取活
✓ 人随时提需求，不用等✓ 调度只需巡检待办✗ 流程变复杂，角色间扯皮

复盘 Agent

观察 → 复盘 → 优化流程本身
✓ 依据最近的调度情况复盘✓ 流程跟着问题一起进化
